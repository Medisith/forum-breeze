# 2026-08-21 — Home com notícias (RSS BR + Guardian) e leitura interna

## Resumo

- Home pública redesenhada no layout de referência (navbar, stats, highlights, tabela + painel lateral).
- Integração de **3 RSS** da Agência Brasil e **1 API** global (The Guardian, `section=environment`).
- Notícias brasileiras espalhadas nas seções da home; painel lateral renomeado para **International News**.
- Clique abre página interna `/news/{id}` (resumo em cache); link opcional para a fonte original.
- Desenvolvimento continua **sem Docker**; cache via Redis (TTL 45 min).

## Arquivos principais

- `app/Services/News/**`
- `app/Http/Controllers/HomeController.php`
- `app/Http/Controllers/NewsController.php`
- `routes/web.php`
- `config/services.php`, `.env.example`
- `resources/js/pages/welcome.tsx`
- `resources/js/pages/News/ShowPage.tsx`
- `resources/js/components/home/**`
- `docs/news-sources.md`, `docs/api.md`, `README.md`

## Breaking / setup

- É necessário definir `GUARDIAN_API_KEY` no `.env` para o painel internacional.
- Após pull: `composer install` (se houver), `npm install`, `npm run dev`, `php artisan cache:clear` se a home mostrar dados antigos.
