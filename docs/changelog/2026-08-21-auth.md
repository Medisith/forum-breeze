## Como validar

1. `php artisan test --filter=test_registration_stores_hashed_password` → PASS.
2. Smoke manual (app + MySQL + Redis rodando):
   - Cadastrar em `/register` → redirect `/forum`.
   - Logout → login com as mesmas credenciais → `/forum`.
   - Senha errada → mensagem genérica (sem revelar qual campo falhou).
3. Após 5 tentativas de login inválidas/minuto (mesmo e-mail + IP) → HTTP 429.
